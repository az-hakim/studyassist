# Signing

Neither artifact is signed unless these secrets exist. Nothing here is required to run the
wrapper locally.

## Android release keystore

Create once, back it up offline — losing it makes future updates impossible:

```bash
keytool -genkeypair -v -keystore release.jks -alias studyassistant \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks   # -> ANDROID_KEYSTORE_BASE64
```

Secrets: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`,
`ANDROID_KEY_PASSWORD`.

`apps/android/android/app/README-signing.txt` (generated by `pnpm android:add`) stays
untouched; read the keystore path from `ANDROID_KEYSTORE_PATH` in Gradle as usual.

## Windows code signing

Provide `WIN_CSC_LINK` (base64 PFX or URL) and `WIN_CSC_KEY_PASSWORD`. Without them
`electron-builder` produces an unsigned installer and Windows SmartScreen will warn users.
Self-signed certificates are for internal testing only.
